# Elle Witkowski | Marketing Portfolio

Single-page portfolio site (plain HTML, CSS, and JavaScript). No build step needed.

## Files
- `index.html` is the whole site.
- `images/` holds all photos. A placeholder on the page is replaced automatically when a file with the matching name is added here (for example `hapi-nani-1.jpg`).

## Publish with GitHub Pages
1. Go to the repo's **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, then pick `main` and `/ (root)`.
3. Save. The site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/` within a couple of minutes.
